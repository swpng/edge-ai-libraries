# Video Search and Summary (VSS)

Video Search and Summarization (VSS) is a foundational sample application that provides
video analytics, using a combination of different AI models. It offers three distinct modes
in which its capabilities can be utilized:

- Video Search ([overview](./Video-Search-Overview-new.md) | [architecture](./Video-Search-Architecture-new.md))
- Video Summary ([overview](./Video-Summarization-Overview-new.md) | [architecture](./Video-Summarization-Architecture-new.md))
- Video Search and Summary ([overview](./Video-Search-and-Summarization-Combined-Overview-new.md) | [architecture](./Video-Search-and-Summarization-Combined-Arch-new.md))
